# 白水电子族谱
白水电子族谱对一个大家庭的族谱数据进行树状化展示。

## ✨ 功能介绍
1. 您可以修改里面的个人信息，可以添加配偶，添加子女（如果是无配偶的子女，请添加配偶为无名氏）
2. 您可以导入在电脑上录入好的数据到手机里面，也可以将更新过的数据导出来，分享给家族里面的其他人。
3. 族谱数据作为一个家族的隐私数据，仅存放在应用程序终端（电脑、手机、微信小程序），通过数据导入的方式传给本程序。

## ✨ 数据录入
将本项目中的index.html和data-template.json5文件下载到电脑上，用浏览器打开index.html文件就可以录入族谱数据。

# Baishui Digital Genealogy
Baishui Digital Genealogy presents family tree data in a tree-structured format.

## ✨ Function Description
1. You can edit individual profiles, as well as add spouses and children. (For children without a listed spouse, please add a placeholder spouse named "Unknown" or "Anonymous.")
2. You can import data—previously entered on a computer—into the mobile application. Conversely, you can export updated data to share with other family members.
3. As private family information, your genealogy data is stored exclusively on your local devices (computer, mobile phone, or WeChat mini-program) and is loaded into the application via the import function.

## ✨ Data Entry
Download the `index.html` and `data-template.json5` files from this project to your computer. Open the `index.html` file in a web browser to begin entering your family tree data.
